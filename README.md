
## Airbnb Clone Project

## Overview
This project aims to replicate core features of Airbnb, including user authentication, property listings, booking functionality, and an intuitive UI/UX.

## Project Goals
- Develop a backend application that enhance key Airbnb management system.
- Implement user authentication and role management.
- Design Airbnb’s booking management system.
- Enable property listing and booking functionalities.
- Integrate payment processing.

## Tech Stack
- **Backend:** Python,Node.js, Express.js,
- **Database:** PostgreSQL, MySQL
- **Authentication:** Django Aunthetication
- **Deployment:** Docker, AWS ,Kubernetes
